# AI agents

Milestone 1 does not implement AI agents.

Later milestones will add an orchestrator with provider interfaces for:

- StrategyAgent
- CreatorProfileAgent
- IdeaAgent
- ContentAgent
- CreativeAgent
- AnalyticsAgent
- GrowthAgent
- PublishingAgent

Prompts will live under `apps/api/app/ai/prompts/` and will be versioned independently of application logic.
